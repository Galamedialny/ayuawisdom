# AYUAWISDOM

Web ajurvédskeho štúdia Dominiky Baranikovej vo Vranove nad Topľou.

Statický viacstránkový web bez závislostí. Vercel: preset Other, bez build command, output directory `.`.

## Lokálne spustenie

`python3 -m http.server 8000`

Kontaktné objednávanie telefonicky. Web nemá kontaktný formulár, analytiku ani cookies. Osobný príbeh, fotografie a právne údaje sa doplnia po dodaní majiteľkou.
